# 创意方向 · 脑暴技法 & 方向模板

## 思维发散工具箱

Phase 1 发散阶段可用的联想技法（不限于此）：

### 1. 极端化
把创意的某个维度推到极端。比如：
- "咖啡杯" → 咖啡杯和城市一样大 / 咖啡杯是宇宙的容器
- "一支笔" → 笔尖划开空间裂缝 / 墨水是星河的浓缩

### 2. 跨界嫁接
将一个领域的核心概念嫁接到另一个领域：
- "手表" + "音乐" → 指针是乐谱的五线谱，齿轮是音符
- "运动鞋" + "自然" → 鞋底的纹路是树根的年轮

### 3. 时空错位
把一个事物放到不属于它的时空：
- 唐朝诗人用 iPad 写诗
- 宇航员在火星上喝功夫茶

### 4. 逆向重构
把常规认知反过来：
- 鱼在空中游，鸟在水里飞
- 不是人在看画，而是画在看人

### 5. 微距化
把一个细节放大成整个世界：
- 一块机械表 → 齿轮是城市，轴心是摩天楼
- 一滴水 → 里面是一个完整的水下世界

### 6. 情绪放大
从一个微小的情绪出发，建筑整个视觉世界：
- "等待" → 等待室无限延伸，墙上指针不动，咖啡凉了又热
- "重逢" → 人群像潮水退去，两个人从两端走向彼此

## 方向提案模板

Phase 2 中每个方向的输出固定为以下结构：

```
## 方向 [编号]：[概念名称]

**一句话概念**：
[用一句话说清楚"看什么"]

**创意亮点**：
[这个方向最特别的地方是什么——让用户觉得"对对对我就要这个"]

**视觉调性**：
[3-5 个关键词]

**情感锚点**：
[想给观众什么感觉？温暖/震撼/荒诞/宁静/不安/好奇...]

**叙事逻辑**：
[2-3 句话描述大致内容走向]

**参考气质**：
[类似什么电影/作品/艺术风格的氛围，1-2 例]

**AI 可行性评估**：
[★★★★☆ 附一句理由]
```

### 三条方向的差异化原则

| | 方向 A | 方向 B | 方向 C |
|--|--------|--------|--------|
| 切入点 | 不同 | 不同 | 不同 |
| 情绪调性 | 差异明显 | 差异明显 | 差异明显 |
| 复杂度 | 有梯度 | 有梯度 | 有梯度 |
| 选谁都合理 | 是 | 是 | 是 |

方向之间不是"好/更好/最好"的递进，而是三条各自成立的路。用户选哪个都不会后悔。
