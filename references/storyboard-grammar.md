# 分镜语法 · 描述 & 提示词写作指南

## 分镜描述（Shot List）写法

Phase 6 输出的分镜表，每镜需包含：

| 字段 | 说明 | 示例 |
|------|------|------|
| 镜号 | 序号 | 1 |
| 景别 | 远景/全景/中景/中近景/近景/特写/大特写 | 中近景 |
| 视角 | 平视/俯拍/仰拍/过肩/第一人称/低角度 | 平视 |
| 画面描述 | 画面内容 + 光影 + 主体/产品状态 | 暖木桌面上咖啡杯冒热气，手指从右侧入画握住杯柄，晨光斜射在表盘上 |
| 时长 | 镜头持续时间（视频） | 3s |
| 转场 | 硬切/叠化/溶解/匹配剪辑/黑场（视频） | 叠化 |

### 景别参考

| 景别 | 作用 |
|------|------|
| 远景 | 建立环境空间感 |
| 全景 | 主体全身 + 环境 |
| 中景 | 主体上半身，兼顾动作和环境 |
| 中近景 | 腰部以上，兼顾面部和手部 |
| 近景 | 胸部以上，聚焦表情/细节 |
| 特写 | 单一细节放大 |
| 大特写 | 极端细节，如齿轮转动、材质纹理 |

### 视角参考

| 视角 | 效果 |
|------|------|
| 平视 | 中性客观 |
| 俯拍 | 上帝视角，全局感 |
| 仰拍 | 主体显得高大/威严 |
| 过肩 | 让观众代入角色视角 |
| 第一人称 | 极强代入感 |
| 低角度贴地 | 压迫感或微小物件的宏大感 |

## 分镜提示词（Phase 7）写作原则

### 通用原则（所有工具通用）

1. **画质锚定前置**：提示词开头用最高优先级的质量词
2. **主体描述明确**：画面中最重要的元素放在最前
3. **光影不可省略**：每条提示词必须有光影设计
4. **构图指示清晰**：景别、视角、镜头运动
5. **一致性锚点**：同系列提示词共享统一的风格锚定词

### 提示词结构矩阵

| 元素 | 权重 | 说明 |
|------|------|------|
| 画质/风格锚定 | 最高 | 决定整体质感 |
| 主体描述 | 高 | 画面中最核心的元素 |
| 动作/状态 | 中高 | 正在发生什么 |
| 环境/空间 | 中 | 在哪 |
| 光影 | 中 | 光线方向和质量 |
| 构图/景别 | 中 | 镜头的选择 |
| 视角 | 中 | 观众在什么位置看 |
| 色彩调性 | 低中 | 整体色温/色调 |
| 画风锚定收尾 | 低中 | 兜底风格描述 |

### 常见错误

| 错误 | 正确做法 |
|------|---------|
| 提示词太长堆砌 | 精炼，一个意思只表达一次 |
| 抽象情绪词代替画面 | 用具体视觉描述代替"温暖"、"孤独"等词 |
| 没有光影 | 每条提示词至少指明光源方向或光质 |
| 景别和视角混用 | 景别是距离远近，视角是观看角度，两个都要写清楚 |
| 系列提示词风格不统一 | 所有提示词开头用统一的风格锚定词 |
