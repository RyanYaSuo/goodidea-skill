# 工具适配器 · 提示词语法参考

Phase 7 需要输出对应工具的分镜提示词时，读取本文件的对应工具章节。只读需要的那一个，不要全部加载。

---

## Nano Banana Pro

中文自然语言提示词，6 层结构：

```
[画质锚定] + [主体描述] + [环境/空间] + [光影] + [构图/镜头] + [画风锚定]
```

**关键规则**：
- 画质锚定前置，画风锚定收尾
- 避免冗余重复，精炼 > 堆砌
- 具体 > 抽象：用具体视觉描述替代抽象情绪词
- 多条提示词共享统一风格锚定词

**画面比例**：16:9（默认）

## GPT-Image2

英文提示词，自然语言描述。

结构参考：
```
[quality/style anchor], [subject description], [environment], [lighting], [composition], [camera/lens], [style reference], [color palette]
```

**关键规则**：
- 开头用最高优先级的质量词（如 `cinematic`, `photorealistic`）
- 主体描述在前，环境和光影在后
- 可以用负面提示词方式，但不强制
- 不需要 MidJourney 风格的 `--ar` 参数

---

## MidJourney

英文提示词，参数化结构。

**基础结构**：
```
[subject] [environment] [lighting] [composition] [style] --ar 16:9 --v 6
```

**关键规则**：
- 主体在最前
- 描述间用逗号分隔，不用"and"
- 用 `--ar` 控制比例，`--v` 控制版本，`--s` 控制风格化程度
- 重要概念前置，不重要的靠后

**常用参数**：
| 参数 | 说明 | 示例 |
|------|------|------|
| `--ar 16:9` | 宽屏 | `--ar 16:9` |
| `--v 6` | 版本 6 | `--v 6` |
| `--s 50-1000` | 风格化 | `--s 250` |
| `--style raw` | 减少 MJ 审美干预 | `--style raw` |

## DALL·E

英文自然语言提示词。

**结构**：
```
[detailed visual description]. [lighting/atmosphere]. [composition]. [style/medium].
```

**关键规则**：
- 详细描述画面内容
- 明确指定艺术风格/媒介
- 可以通过"no X"来排除不需要的元素
- 不需要宽高比参数（DALL·E 按需裁剪）

## Seedance

Multi-Phase 视频提示词，中文。

```
风格：[视觉风格] / [色彩基调] / [光影系统] / [约束条件] / 无背景音乐 产品@产品多视图图片 的广告

Phase 1 (0-Xs): [标题]
[景别+视角] [运镜描述]。[产品/主体状态变化]。[光影效果]。

Phase 2 (X-Ys): [标题]
[节奏变化]。[运镜]。[主体动态]。[光效变化]。

Phase 3 (Y-Zs): [标题]
...
```

**关键规则**：
- 每段视频独立编号，Phase 从 1 开始，秒数从 0 开始
- 风格声明末尾必须"无背景音乐"
- 双图输入：首帧参考图 + 产品多视图

## 即梦

中文视频提示词。

**结构参考**：
```
[镜头描述]，[主体动作]，[环境氛围]，[光影色调]，[画质要求]
```

Multi-Phase 格式可参考 Seedance 的写法做适配。
